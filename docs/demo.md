# Presentation runbook

1. Start the web app and open `/citizen`, `/dashboard`, and `/worker` in separate tabs.
2. On Citizen, choose **Report an issue**, enter “Overflowing garbage near school”, grant location, take a photo, and submit.
3. On Admin, the report appears in Live Work Orders. Choose **Assign**.
4. On Worker, open the new assignment. Use a seeded far-away task first to demonstrate **Proof rejected** with calculated distance.
5. Open the just-created task, start verification, grant precise location, and capture selfie/before/after evidence.
6. Submit the proof. Return to Citizen; open the report and select **NO — Dispute work**.
7. On Admin, open **Investigations** and review “Possible organised ghost-work — Ward 8”, the geo pattern, impossible-travel timeline, contradiction rate, and financial exposure.

Browser demo state is saved in local storage and synchronized across tabs. Use **Reset presentation data** at the bottom of the dashboard before rehearsing again.
